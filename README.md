# BioBuddy – Smart Bio Generator

BioBuddy is a modern, responsive web application that helps users create perfect bios for various social media platforms and professional profiles. Built with HTML, Tailwind CSS, and vanilla JavaScript, it offers a seamless experience for generating engaging and platform-appropriate bios.

## Features

- **Multi-Platform Support**: Generate bios for Instagram, LinkedIn, Freelance platforms, and Dating profiles
- **Multiple Tone Options**: Choose from Professional, Funny, Friendly, and Romantic tones
- **Instant Generation**: Get three unique bio variations with each submission
- **Dark Mode**: Comfortable viewing experience with automatic system preference detection
- **Responsive Design**: Works perfectly on all devices - mobile, tablet, and desktop
- **Local Storage**: Remembers your last generated bios
- **Copy to Clipboard**: One-click copying of generated bios
- **No Login Required**: Use instantly without any registration
- **Privacy-Focused**: No data collection or API calls

## Tech Stack

- HTML5
- CSS3 (Tailwind CSS)
- Vanilla JavaScript
- Local Storage API
- Clipboard API

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/biobuddy.git
   ```

2. Open the project folder:
   ```bash
   cd biobuddy
   ```

3. Open `index.html` in your browser or serve with a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve
   ```
